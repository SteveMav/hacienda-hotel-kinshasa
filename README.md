# Hacienda Hôtel Kinshasa - maquette de proposition

Site statique de prospection freelance pour Hacienda Hôtel Kinshasa.

Ce dépôt présente une maquette non officielle destinée à ouvrir une discussion commerciale autour d'un futur site officiel : chambres, restaurant Côte à Côte, lounge, coordonnées, réservation WhatsApp et informations locales.

## Fichiers publics

- `index.html` : page de présentation complète.
- `styles.css` : thème clair/sombre, responsive et composants.
- `script.js` : menu mobile, préférence de thème et formulaire WhatsApp.
- `images/` : visuels bitmap générés pour la maquette.

Le dossier `mailsender/` est volontairement ignoré par Git, car il contient les scripts et variables d'envoi email locaux.
